Put every window in its place.

Animated window snapping for Linux X11. Send the active window to a half, quarter, centre or another monitor, then return it to its home position.

In use

01

Move with a shortcut

Snap to a grid position, centre the window or toggle fullscreen with configurable padding.

02

Across your displays

Use RandR monitor detection to move windows between screens.

03

A small background daemon

Answer hotkeys and collapse key-repeat bursts, with settings stored in a simple configuration file.

Get started

Set up your shortcuts

Install WinJitsu, xdotool and python-xlib on an X11 desktop (on Arch-based distributions, a single AUR package covers all three). Start its daemon before using actions, then bind the commands to your window manager's shortcuts. See the README for configuration and autostart.
